# tic-tac-toe
a simple 2 player tic tac toe game with score and match reset option

## two player game
- you can play game with your friends 
  - it have robust score system and 
  - reset game option

## how to play
1. run this command `git clone https://github.com/Rishabingh/tic-tac-toe.git` in and directory
2. install vs code live server extension or double click the html file in file explorer to run game directly thats it.
3. or open it with vs code and do right click and then open with live server
